## 1. Deskripsi Project
Project ini merupakan hasil Praktikum 7 mata kuliah Pemrograman Web yang membahas pemrograman server-side menggunakan PHP. Praktikum ini bertujuan memahami dasar PHP, mulai dari penggunaan variabel, operator, percabangan, perulangan, function, hingga pemrosesan dan validasi data menggunakan form GET dan POST.

## 2. Tujuan Praktikum
- Memahami konsep pemrograman server-side dengan PHP.
- Menerapkan variabel, operator, percabangan, perulangan, dan function.
- Memahami penggunaan metode GET dan POST.
- Melakukan validasi dan sanitasi input pengguna.
- Membuat aplikasi sederhana untuk mengelola data mahasiswa.

## 5. Alur Project
Project dikerjakan secara bertahap dengan urutan berikut:

1. **Latihan 1:** Menjalankan PHP dan menampilkan output pada browser.
2. **Latihan 2:** Menggunakan variabel, operator, dan percabangan untuk menghitung nilai mahasiswa.
3. **Latihan 3:** Menggunakan array dan perulangan untuk menampilkan daftar mahasiswa.
4. **Latihan 4:** Membuat function untuk menghitung harga setelah diskon.
5. **Latihan 5:** Memproses data pencarian menggunakan metode GET.
6. **Latihan 6:** Menerima dan memvalidasi data mahasiswa menggunakan metode POST.
7. **Latihan 7:** Mengolah data transaksi barang dan menghitung subtotal.
8. **Mini Project:** Membuat formulir data mahasiswa dengan validasi dan menampilkan hasil data yang telah dikirim.

## 6. Cara Menjalankan Project
1. Buka XAMPP Control Panel.
2. Aktifkan Apache.
3. Simpan folder `Lab7Web_PHP` di dalam direktori `C:\xampp\htdocs\`.
4. Buka browser.
5. Masukkan alamat berikut:

   `http://localhost/Lab7Web_PHP/`

6. Pilih file latihan yang ingin dijalankan.
